API Specification & Contract
POST /api/auth/login/ User Authentication

Authenticates user and returns session credentials and role profile.

{"username": "Sakthi", "password": "..."}
GET POST /api/claims/ List & Ingest Claims

Query claims with pagination, status filtering, and search parameters.

POST /api/claims/{claim_id}/process/ Execute Master Processing Pipeline

Executes OCR document reconciliation, clinical validation rules, and AI fraud risk scoring.

POST /api/documents/{document_id}/ocr/ OCR Document Processing

Triggers OCR text and entity extraction for uploaded medical records or bills.

POST /api/fraud/analyze/ Alias: /api/ai/analyze/ Direct AI Risk Evaluation

Accepts either an existing claim ID or raw JSON parameters for real-time anomaly evaluation.

{"patient_name": "Meera Iyer", "procedure": "Cataract Surgery", "amount": 65000, "duplicate_claim": false}
POST /api/external-claim/ External Webhook / Ingestion

Ingests external provider claims into the repository.

GET /api/health/ System Status Check

Returns operational health of databases, AI engine, and services.
